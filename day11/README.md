# Day 11：重構與型別標註

從 Day 08～10 選最混亂的一份程式複製至本目錄。

## 強制要求
- 公開函式有完整型別標註與 docstring（函式用途說明）。
- 主要函式原則上不超過 30 行。
- 消除明顯重複。
- `main()` 只協調流程。
- I/O 與計算分離。
- 重構前後測試皆通過。
- 不改變既有 CLI 行為。

## notes.md 額外回答
重構前問題、採用的重構、如何確認行為不變、刻意未重構之處。

## 測試
沿用原測試並新增至少 3 個。

## 口頭驗收
哪個函式是 pure function？哪些 dependency（外部相依物件）最難測？

## 延伸知識
看 `CONCEPTS.md`（解題前或解題後皆可）。
